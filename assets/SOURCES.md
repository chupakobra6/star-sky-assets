# Artwork sources

The standalone Star Sky Mods mark preserves the geometry of the original Starboard logo. The white-on-black version inverts its original colours. Star Sky Mods’ rounded frames, version ribbons, section headers and typography are composed with vector tools. The collection cover backgrounds are ImageGen artwork created for these collections; other brand backgrounds remain vector compositions.

The three ISEKAI covers use frame 0 of the **800 × 450** [original artwork](https://images.steamusercontent.com/ugc/12230229214356412021/59AE4D6DDC7C4D2DF10F81734F88B4BB70BF7631/) from [ISEKAI RPG LEVELING](https://steamcommunity.com/sharedfiles/filedetails/?id=3657580708), by **POUPUN**. The source GIF contains 63 frames. Our covers add titles and a frame to the original artwork.

## Collection covers

The Mods and Russian Translations covers share a single Star Sky Mods composition: an illuminated planetary crescent, a four-point star and an approaching ship. Mods uses a warm planet; Russian Translations preserves the same composition with a cool planet, city lights and communication antennae. Future category variants retain these main elements and their placement, changing the palette and thematic details. The scene itself carries the brand motif, so collection covers do not add a separate corner logo. The standalone deterministic logo remains in use on other assets.

The scene backgrounds were created with ImageGen for this project, without third-party mod or game artwork. The pinned 1672 × 941 PNG inputs are `assets/sources/collection-mods-background.png` (SHA-256 `4c7b5ee0f6f0d16b130aab84140561a3281c818a11c774d3f932131fdf599ce8`) and `assets/sources/collection-translations-background.png` (SHA-256 `0802e09e09e570c1b7d0d367168f927057fe46a3ebfd07eeaac6121ec07ecf26`). The existing artwork renderer adds the rounded frame, Russo One title and, for Russian Translations, the RU flag. Published covers are 800 × 450 with no game version badge. Typography is not generated by ImageGen.
